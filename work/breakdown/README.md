# 詞語拆解

點一段歌詞詞組時，提示會一次列出整段的拆解。每首一個檔案，`python3 work/apply_breakdown.py <歌曲 key>` 會把內容寫進 `dist/data/lyrics.json` 與 `lyrics.js`。

## 原則

- 詞組維持原本的一小段，只在提示裡拆開。
- 說明用白話，不用文法術語（不寫「使役」「て形」「連用形」）。動詞寫成「原形（意思），接到下一段」。
- 標籤只用在特別的時候：`慣用語`（固定說法）、`口語`、`方言`。一般詞組不加。
- 有值得學的句型才寫 `g`，格式「〜のがいい ＝ 做…比較好」。
- 漢字部分附讀音，假名部分讀音留空。

## 動詞與句尾的寫法

- 動詞寫「原形（意思）」，再用白話說變化：`揺れて`：揺れる（搖晃），接到下一段；`行きたい`：行く（去）＋ たい ＝ 想去。
- 常見結尾固定說法：ない「不…、沒有」；たい「想…」；た「…了（已經發生）」；ます「客氣的句尾」；です「客氣的句尾，「是…」」；だ「句尾「是…」，口吻直接」；よう（〜しよう）「來…吧」。
- 標籤：口語＝隨性的縮短或說法（ちゃう、てる、んだ、じゃん、あんた、あたし）；方言＝岡山腔／關西腔等（ええ、〜けぇ、〜じゃ、おる、〜とる、ほんま）。藤井風常用岡山腔，遇到時寫出標準說法。
